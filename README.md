# Vectra releases

This repository hosts the installers and auto-update files for the Vectra desktop app (macOS, Windows and Linux).
Download the latest version from the [Releases](https://github.com/zenbytesolutions/vectra-releases/releases) page.

Vectra's source code is private. This repository holds only release files and no code.

The builds are not code-signed. The first time you open one:

- **macOS:** right-click (or Control-click) Vectra.app, choose Open, then Open again. On macOS 15 or later, if there is no Open button, go to System Settings ▸ Privacy & Security and click Open Anyway.
- **Windows:** if SmartScreen says "Windows protected your PC", click More info, then Run anyway.
- **Linux:** make the AppImage executable (`chmod +x Vectra-*.AppImage`) and run it, or install the .deb.
